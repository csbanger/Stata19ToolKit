How to use this page

Reading a Stata command

Stata commands follow the same shape nearly every time. Once you can see that shape, an unfamiliar command stops being frightening and becomes a fill-in-the-blanks exercise. 

summarize price mpg, detail
--------- ---------  ------
command   variables  options
  • The command comes first and is always one or two words.
  • The variables it should act on come next, separated by spaces.
  • Anything after the comma is an option that changes the behaviour.
  • An if condition, when you need one, goes before the comma.

Three habits worth building

Copy, do not retype. Every example here starts with sysuse auto, clear, so you can paste the whole block straight into Stata and watch it run. Most beginner errors are typos, not misunderstandings.

Check the official syntax. Options differ between Stata versions. help summarize shows the exact syntax your copy accepts.

Run one line at a time. If a block of four commands fails, you want to know which one broke.

Stuck on an error rather than a command? The Help Centre translates Stata’s error messages into English.
