Who this is for

Written for the person who has never typed a command before

If you have only ever used Excel, Stata feels unfriendly. There is a blinking cursor, no obvious buttons, and error messages written for people who already know what they mean. None of that means you are bad at statistics.

  • Every example uses a dataset that ships with Stata, so you can run it right now.
  • No jargon without a definition, and no assumed knowledge of the command line.
  • Explanations stay short. If you want the full reference, Stata’s own help is better.
  • Copy buttons on every code block, because typos are the number one cause of errors.

Try this right now

Open Stata, click into the Command window and type these two lines. The first loads a dataset that came with your copy of Stata; the second summarises it. 

sysuse auto, clear
summarize price mpg

If that produced a table of numbers, you have just run your first Stata analysis. The Beginner Guide explains every part of it.

The shape of a session

Four moves, every single time

Nearly every piece of Stata coursework is the same four steps in the same order. Once that is familiar, the only thing that changes between assignments is the middle.

Step one

Point Stata at your folder

cd once at the top, and every file afterwards can be named on its own.

Step two

Load and look

use or import, then describe before you analyse anything.

Step three

Summarise, then test

summarize and tabulate first; the model comes after you know the data.

Step four

Save the evidence

graph export and a log file, so your report writes itself.
